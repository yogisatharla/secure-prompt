## 🌟 Overview

**Secure Prompt** is a visually stunning, highly interactive privacy firewall designed for the AI era. It acts as a protective shield between your users and Large Language Models (LLMs), automatically detecting, redacting, and eliminating sensitive data leakages—such as Personally Identifiable Information (PII)—before the prompt ever leaves your environment.

Built with a modern, high-performance tech stack, Secure Prompt doesn't just protect your data; it delivers an unparalleled user experience with immersive 3D physics, fluid animations, and beautiful micro-interactions.

---

## ✨ Key Features

- **🛡️ Real-Time PII Redaction**: Instantly detects and sanitizes sensitive entities (names, emails, credentials, financial data) from text.
- **📊 Interactive Risk Insights**: Visual risk meters and dynamic analytics that assess prompt safety before execution.
- **🪄 Stunning UI/UX**:
  - **Magic Bento Layouts**: Clean, modular, and fully responsive data presentation.
  - **Immersive 3D Physics**: Powered by `react-three-fiber` and `rapier` for delightful physics-based interactions (like interactive lanyards).
  - **Cinematic Effects**: Featuring `PixelBlast`, `LightRays`, `BorderGlow`, and `ClickSpark` animations.
  - **Cryptic Scrambled Text**: Hacker-style text reveal animations for redacted data.
- **⚡ Blazing Fast**: Built on Vite and React 18 for instantaneous feedback and minimal overhead.

## 🚀 Getting Started

Follow these steps to run Secure Prompt locally on your machine.

### Prerequisites
- Node.js (v18 or higher recommended)
- npm, yarn, pnpm, or bun

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/secure-prompt.git
   cd secure-prompt
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or yarn install
   # or bun install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open the application**
   Navigate to `http://localhost:3000` in your favorite browser.
